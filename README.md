# Diferencijalna Evolucija

### Opis

Ovaj projekat implementira algoritam diferencijalne evolucije, koji je evolucionarni algoritam za optimizaciju funkcija. Projekt je realiziran kao zadatak iz predmeta Računarska inteligencija.

### Sadržaj

* Implementacija algoritma diferencijalne evolucije
* Primeri korišćenja i testiranja algoritma
* Dokumentacija i komentari u kodu

### Napomene

* Ovaj projekat je realiziran kao zadatak iz predmeta Računarska inteligencija.
* Korišćeni su principi evolucionarnih algoritama za optimizaciju funkcija.
* Projekt je otvoren za dalje razvijanje i poboljšanje.
